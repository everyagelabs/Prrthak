## Code defects

| Review | Status and change | Evidence / acceptance limit |
| --- | --- | --- |
| **B1 · Endpoint configuration rollback** | Fixed in code. Restore and commit share a generation lease; a stale or unreadable active-review binding cannot overwrite a successor. Refused restoration returns an error instead of success. Installer replacement holds the same lease through copies/start. | [Transition and recovery](../agent/internal/agent/configuration_transition.go), [successor-fencing regression](../agent/internal/agent/configuration_fencing_test.go), [transition tests](../agent/internal/agent/configuration_transition_test.go), [installer tests](../tests/test_installer.py). Failed/uncertain recovery remains blocked and logged. Current native lockout acceptance is still M5/S4. |
| **B2 · Entra/PyJWT dependency** | Fixed in code. Entra initialization refuses unsupported PyJWT versions; the supported range is **>=2.10,<3** with cryptography. Audience/time/issuer/tenant checks remain explicit. | [Authentication](../controller/auth.py), [requirements](../controller/requirements.txt), [adversarial authentication tests](../controller/tests/test_auth.py). Live tenant/MFA acceptance is still pending. |
| **B3 · Cached signing-key permission test** | Fixed in code. The signer checks private-key safety on every accessor; deterministic regressions cover cached signer invalidation without depending on a polling interval. | [Signer runtime tests](../controller/tests/test_policy_signer_runtime.py), [policy signing](policy-signing.md). Final aggregate results belong in the release record below. |
| **B4 · Linux command-lease descriptor ownership** | The command retains an independent descriptor using atomic CLOEXEC duplication while the original file is protected against concurrent close. Closing the owner no longer races child startup; the inherited enforcement lock remains held until the command tree drains. Every run/start-error path closes its owned reference. | [Runner](../agent/internal/agent/process_linux.go), [owner-close, cancellation and concurrent-construction regressions](../agent/internal/agent/process_linux_test.go). The initial `v0.7.0-pilot.1` Linux CI exposed this race; candidate `.2` supersedes it. Linux ARM64 full race/vet passed; eight fencing cases repeated 20 times passed in 71.534 s, including 1,280 concurrent-close attempts. Native firewalld/DC acceptance remains M5/S4. |
| **B5 · Strict TLS controller-join issuance** | Joined-controller leaves now carry appropriate critical key usage, subject key identifier and issuer key identifier. The real issued certificate verifies strictly for its DNS and IP names. Recovery test PKI now meets the same strict requirements; TLS verification stays enabled. Positive manager/CLI fixtures use canonical OS temporary roots. | [Issuance](../controller/platform.py), [actual join regression](../controller/tests/test_platform.py), [strict recovery HTTPS](../tests/test_recovery_https.py). Both targeted tests passed on Linux Python 3.13 and local Python 3.12. Eight production generation paths pass strict verification. Native/DC/live-tenant acceptance remains separate. |
